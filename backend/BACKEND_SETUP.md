# Backend Setup Guide

This document describes how to set up and run the Drug Inventory Management backend locally.

## Prerequisites
- Node.js (v18 or higher recommended)
- npm (Node Package Manager)
- SQLite (The project uses `better-sqlite3`, so SQLite is handled natively within Node)

## Installation

1. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```
   > **Note**: This will install Express, SQLite drivers, Winston (for logging), and Helmet (for security headers).

3. Setup environment variables:
   Copy `.env.example` to `.env` (if it exists) and fill in the necessary variables.
   ```bash
   cp .env.example .env
   ```
   *The primary variable needed is `PORT` (default is 3000).*

## Database Setup

The backend uses a local SQLite database for development.

To initialize the database and create all tables:
```bash
node src/database/migrate.js
```
This will create a `database.sqlite` file in the `backend` root and run `001_initial_schema.sql` to generate the schema tables.

## Running the Server

Start the development server:
```bash
node server.js
```

The server will start on `http://localhost:3000` by default. You can test if the server is running by hitting the health check endpoint:
```
GET http://localhost:3000/api/health
```

## Project Structure
- `src/app.js`: Express app setup, middleware, and route registrations.
- `src/database/`: SQLite connection (`database.js`), migrations, and schema definitions.
- `src/middleware/`: Custom Express middlewares (e.g., error handler, logger).
- `src/routes/`: Route definitions for different domains (auth, drugs, procurement, warehouse, etc.).
- `server.js`: Server entry point.
- `logs/`: Application logs (generated by Winston).
